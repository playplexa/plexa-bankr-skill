## What is this?

Official **Bankr Skill** for [PLEXA](https://plexa-sepia.vercel.app) — a clean onchain slot game on Base Mainnet.

After installing, you can play using natural language:

- `deposit 5 USDC to plexa`
- `spin 0.25 USDC on plexa`
- `check my plexa balance`
- `withdraw 2 USDC from plexa`
- `withdraw all from plexa`

---

## Features

- Deposit USDC or $BNKR
- Spin with your in-game balance
- Withdraw anytime
- Clear win/loss feedback
- Fully onchain on Base Mainnet
